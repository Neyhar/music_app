# Music_App Repository

This repository contains a music transcription and management application with separate backend and frontend components.

## Major directories

- `backend/`: API server, database models, transcription services, and worker logic.
- `frontend/`: Vite-based web client built with TypeScript and React.
- `docs/`: Project documentation and model selection notes.
- `storage/`: Stored audio and MIDI assets used by the application.
